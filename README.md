### Project Description

InsightIQ is an AI-powered business analytics dashboard designed to provide
business performance insights, revenue analysis, sales information,
customer information, inventory alerts, and AI-generated business insights.

### Features

- Dashboard
- Analytics
- Sales
- Customers
- Products
- Inventory
- Finance
- Reports
- AI Insights
- Interactive prototype navigation
